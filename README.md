
# 🎓 EstágioMatch

### Sistema de Busca e Recomendação de Vagas de Estágio em TI

## 📌 Sobre o projeto

O **EstágioMatch** é um projeto acadêmico desenvolvido em linguagem C para a disciplina de Algoritmos e Pensamento Computacional, do curso de Análise e Desenvolvimento de Sistemas da Universidade Positivo.

O objetivo do projeto é simular um sistema de busca de vagas de estágio na área de Tecnologia da Informação, permitindo que o usuário encontre oportunidades de acordo com sua área de interesse.

## 🎯 Objetivo

Aplicar conceitos fundamentais de programação em C por meio de um sistema que realiza buscas, organiza informações e processa dados relacionados a vagas de estágio em TI.

## 💻 Áreas disponíveis

O sistema possui 15 vagas cadastradas, distribuídas entre cinco áreas:

- Desenvolvimento de Software
- QA e Testes
- DevOps
- Banco de Dados
- Segurança da Informação

## ⚙️ Funcionalidades

- Busca de vagas por área de interesse;
- Exibição do nome da empresa, área, modalidade e valor da bolsa;
- Contagem das vagas encontradas;
- Cálculo da média dos valores das bolsas;
- Identificação da maior e da menor bolsa;
- Seleção de uma vaga;
- Confirmação ou cancelamento da candidatura simulada;
- Possibilidade de realizar novas buscas;
- Validação das opções informadas pelo usuário.

## 🧠 Conceitos de programação aplicados

Durante o desenvolvimento, foram utilizados os seguintes conceitos:

- Variáveis e tipos de dados;
- Entrada e saída de dados com `scanf` e `printf`;
- Operadores e expressões;
- Estruturas condicionais `if`, `else if` e `else`;
- Estruturas de repetição `for`, `while` e `do while`;
- Vetores e índices;
- Busca e processamento de dados;
- Soma, média, contagem e comparação de valores.

## 🗂️ Organização dos dados

O sistema utiliza vetores para armazenar e relacionar as informações das vagas:

- `empresa`: nomes das empresas;
- `area`: códigos das áreas de interesse;
- `modalidade`: modalidades das vagas;
- `bolsa`: valores das bolsas;
- `vagasEncontradas`: posições das vagas correspondentes à área selecionada.

Os vetores principais utilizam índices correspondentes para relacionar as informações de cada vaga.

## 🔎 Como funciona

1. O usuário escolhe uma área de interesse no menu.
2. O sistema percorre as vagas cadastradas e identifica aquelas que correspondem à área selecionada.
3. As informações das vagas encontradas são exibidas.
4. O sistema apresenta a quantidade de vagas, a média das bolsas e os valores máximo e mínimo.
5. O usuário pode selecionar uma vaga e confirmar ou cancelar a candidatura simulada.
6. Ao final, é possível realizar uma nova busca ou encerrar o sistema.
